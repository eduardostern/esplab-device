# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button
(Security tab of this repository), not in public issues. Include the firmware version (`ESP Lab Runtime x.y` on the serial
console) and steps to reproduce. You'll get an answer within a few days, and credit in the release
notes if you want it.

In scope: the firmware, the recovery app, the local control page and its access code, OTA, and
the device side of the cloud protocol.
